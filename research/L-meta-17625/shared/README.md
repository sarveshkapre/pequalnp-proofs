# When shared wires can distinguish residual edges

Suppose there are *k* pairs and we can build a negative input for every choice of one endpoint of each pair. Each negative contains the chosen endpoints. On the circuit side, each pair alone turns on some wire in a fixed collection, while all these wires stay off on every chosen negative.

For each negative, record one bit per relevant AND. At a false AND select one of its false inputs. A true AND permits either choice. If two negatives allowed the same record, consider a pair on which they chose opposite endpoints. Both endpoints appear in their union. Trace down the wire which detects that pair. At an OR, follow any true input. At an AND, follow the input named by the record. The trace shows that at least one negative would turn that wire on. Hence each of the 2ᵏ negatives requires a different record. This allows any amount of wire sharing. [Lean proof](SwitchCore.lean)

For a circuit in top form, every AND reached under another AND is dirty, meaning it accepts some set of vertices containing no edge. If there is an observed AND at the top, include its bit as well. When there are exactly *k* bits, every possible record must occur. A gate with equal inputs on even one chosen negative would make two different records valid for that negative, so every recorded AND must have exactly one true input there. [Equality case](SwitchCore.lean)

A centreless top is an AND whose one side has no path consisting solely of ORs to an input variable. That side can turn on only by reading a dirty AND. Under equality all recorded ANDs are off on each chosen negative. The empty side must therefore always be off, which fixes that top's bit. Equality would require records with this bit set either way. Consequently *k* < *J* + *H* when there is at least one centreless top, where *J* counts dirty ANDs and *H* counts centreless tops. This holds for any number of eligible OR gates. [Strict bound and exact circuit hypotheses](CentreSwitch.lean)

The choice of negative inputs is a material hypothesis. It follows when every vertex cover costs one vertex per ordinary top and one per residual edge. With one spare cover vertex this argument can fail. [Cover construction](../cover/ExtremalCover.lean) · [Counterexample with one spare vertex](../cover/SlackExample.lean)

When all tops have centers, the unrestricted result is *k* ≤ *J*. For *J* ≤ 3 and at most two eligible ORs, a pre-existing six-clause bound gives the additional conclusion *k* ≤ 2. [All-centered circuit proof](ProtectedTriple.lean) · [Graph formulation](ExtremalRouting.lean)

There is also a bound independent of the number of centreless tops. Record three possibilities at each dirty AND. It is on, it has its first input off, or it has its second input off. If both inputs are off, choose the first. Two negatives with identical records agree on every dirty AND. For any centreless top firing on a pair, its empty side reads a dirty AND that fires on that pair. The earlier tracing argument forces that dirty AND to fire on one of the two negatives, hence on both. The other side fires on at least one negative as well. This would turn on the centreless top there. Thus the same records cannot serve two different transversal choices. Four protected pairs already require three dirty ANDs, since two dirty ANDs have only nine possible records for sixteen choices. In general, 2ᵏ ≤ 3ᴶ.
